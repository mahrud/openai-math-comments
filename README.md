# Human commentary on OpenAI

This repository is a public square for collecting commentary on [OpenAI's mathematics solution dump](https://github.com/openai/math), created in response to a suggestion by Ben Elias. The goal is to amass the collective impressions of mathematicians in their own areas of expertise.

Each manuscript group has its own pull request for discussion. You must login to GitHub to leave a comment. You can either leave a general comment directly on the pull request, or leave a comment on a particular line or section of the source code.

**DON'T BE A MEAT PROXY: LLM-generated comments are not permitted and will be removed.** Write your own commentary, and please be respectful and act as professional representatives of the mathematical community.

Suggestions, bug reports, and contributions should be sent by email.
